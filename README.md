An interactive, telemetry-inspired developer portfolio and system observatory built for the **One Who Codes 2026** portfolio challenge.

---

## 🌟 Highlights & Features

* **3D Particle & Observatory Canvas:** Interactive WebGL background rendering a rotating radio telescope and particle field using Three.js.
* **Live HUD Telemetry:** Interactive cursor tracking updating azimuth and altitude coordinates in real-time.
* **Interactive CLI Terminal:** Embedded virtual terminal supporting command execution (`sih`, `projects`, `skills`, `contact`, `clear`).
* **Signal Telemetry Modals:** Detailed architecture, system metrics, and repository links for key engineering projects.
* **Responsive Dark Observatory UI:** Styled with Tailwind CSS, custom glow animations, and Lucide vector icons.
